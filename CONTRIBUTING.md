# Contributing to the training repository

- Keep all sample data synthetic and non-sensitive.
- Do not commit passwords, tokens, keys, connection strings or tenant-specific secrets.
- Keep lab instructions reproducible from a clean Skillable environment.
- For each lab, document prerequisites, exact steps, expected results, common errors, cleanup and evidence to export.
- Prefer small, clearly named files and relative links within the repository.
- Test notebook and SQL examples in the target Fabric/Skillable environment before marking a lab as validated.
