# Lab 07 – Security, Governance, Git and Deployment

## Objective
Prepare the Fabric solution for controlled team development and deployment.

## Activities
1. Review Admin, Member, Contributor and Viewer roles using only the permissions provided in Skillable.
2. Inspect Lakehouse and Warehouse permissions; discuss least privilege and separation of engineering and consumption access.
3. Open lineage for representative Lakehouse, notebook, pipeline and Power BI artifacts where supported.
4. If Git integration is enabled, configure the approved provider/repository, select branch and folder, commit supported artifacts, sync and resolve a simple conflict. Otherwise export notebook/SQL sources and practice source control locally.
5. If deployment pipelines are available, create/use Dev and Test workspaces, assign stages, deploy supported artifacts, configure environment-specific connections/parameters and validate.
6. Create a deployment checklist covering approvals, validation, access, connections, rollback and monitoring.

## Deliverables
Security/role matrix, lineage evidence, Git commit or exported source files and deployment checklist.

## Self-paced task
Propose a production access model for data engineers, analysts and report consumers.
